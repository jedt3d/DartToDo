# DartToDo final icons — dark and light

Final folded-check artwork with the borders added by the user in Figma.

- [Final review board](https://www.figma.com/design/P72xp9CQ7S1SkSqLdn7ORO?node-id=15-452)
- [Editable Appearance component set](https://www.figma.com/design/P72xp9CQ7S1SkSqLdn7ORO?node-id=15-451)

Both masters and the 480, 64, 32, and 16px board instances include matching inside borders. Dark uses #29B6F6; light uses #0077B5. Thickness preserves the user’s 20px stroke at 480px: 4.1667% of the icon width. The five paths forming the folded check are unchanged.

For each appearance:
- 1024px editable icon SVG and PNG.
- 64, 32, and 16px SVG and PNG exports.
- A transparent 816px SVG of the standalone folded check, without the background tile or its border.

The comparison PNG shows both appearances and all small preview sizes. Exports were checked for expected dimensions and borders; the Figma board was visually reviewed. Typography remains Inter on the board; icon artwork has no font dependencies.

Only the final dark/light icon design and its component set remain in the dedicated Figma page. Superseded A/B/C concept masters, the old comparison board, original exploration files, reference copies, and obsolete packages have been removed.

These authoritative design exports are applied to the native iOS/macOS asset catalogs. See the [integration record](../../icon-integration.json) and [trial report](../../../trial/final-report.md) for packaging, build and runtime evidence.
