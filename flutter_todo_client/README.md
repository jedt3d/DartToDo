# FlutterToDo generated client

Typed Serverpod 3.4.12 client for the local-only FlutterToDo backend. Import `package:flutter_todo_client/flutter_todo_client.dart`; use `Client('http://127.0.0.1:8870/')` and close it with its owner. Model sources and endpoint signatures live in the sibling server package; regenerate there instead of editing generated Dart.

See [endpoint contract](doc/endpoint.md). With the local backend running, `dart run tool/live_smoke.dart` checks HTTP transport and generated response decoding.
